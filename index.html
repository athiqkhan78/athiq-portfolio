Case Studies

Process Automation · Small Array

Cutting employee onboarding from 4 hours to 45 minutes

Situation
Every new hire's setup was fully manual — OS installation, driver hunting, account creation, license assignment, access grants. It consumed half a working day per person and left new joiners idle on day one.
Action
  • Built a standardised OS image with pre-loaded apps, drivers, and security baseline (BitLocker, antivirus, patch level)
  • Created provisioning checklists covering Azure AD account creation, Microsoft 365 license allocation, group memberships, and shared-drive access
  • Mirrored the process in reverse for offboarding — access revocation, license reclaim, device wipe and recovery
Result
Onboarding time dropped ~83% (4 hrs → 45 min), 100% offboarding compliance, zero security incidents across every cycle.

Incident Response · Small Array

Recovering a failed production server in 4 hours — zero data loss

Situation
A critical server hosting shared drives failed during business hours at a 50+ user company. Every department's daily work depended on it, and I was the only IT resource on hand.
Action
  • Triaged the failure and isolated the affected services to stop the issue from spreading
  • Restored from the backup protocols I had designed and tested earlier — this is exactly the scenario they existed for
  • Verified data integrity and permissions before reconnecting users, then documented the incident and root cause for management
Result
Full restoration in 4 hours with zero data loss. Business disruption avoided; backup strategy validated in production.

How I Work

/01

Document first

Every fix becomes an SOP or knowledge-base entry. My goal is an IT environment that runs on process, not on one person's memory.

/02

Communicate in plain language

Users don't need jargon — they need to know what happened, what I'm doing, and when it'll be fixed. Clear updates at every stage.

/03

Prevent, don't just fix

Recurring tickets are a signal, not a workload. I track patterns in Freshdesk reports and fix the root cause — patching, policy, or training.

/04

Security by default

MFA, BitLocker, compliance policies, least-privilege access, and clean offboarding — enforced everywhere I've worked, with zero incidents.
